# Kratos for Simple PHP Blog

将 [seatonjiang/kratos](https://github.com/seatonjiang/kratos) 的 **4.3.4** 移植到 Simple PHP Blog **1.14.16+**。参考提交：`6be10d3a97c125f612e0b7ab9f29e9b72828283a`。

## 安装

将整个 `kratos` 目录放进博客的 `themes/`，进入「后台 → 主题管理」预览或启用 **Kratos**。无需 WordPress、Node.js、构建工具或额外 PHP 扩展。

## 还原范围

保留原版完整 CSS、Bootstrap 栅格、海岸 Banner、文章卡片、置顶/热门角标、文章详情、作者工具栏、上下篇、侧栏、分页、页脚与浮动工具。图片、字体、图标和 LightGallery 1.4.0 均本地提供。手机端沿用原版收起导航和隐藏侧栏的布局。

默认显示原版个人简介、文章聚合（最新 / 热点 / 随机）、标签聚合小工具。站点名、文章、分类、标签、独立页面、友链、作者资料和备案号接入博客现有设置。默认头像使用原版占位图；作者设置了头像时优先使用作者头像。热点沿用原版最近 30 天范围和 6 篇的数量。

主页搜索通过 `?s=关键词` 提供，支持文章标题、摘要和公开正文，分页保留搜索条件。密码正文与回复隐藏区块始终在检索前移除，不会出现在列表封面、摘要、侧栏或搜索结果中。搜索扫描已发布文章，文章数量很大时耗时会随数据量增加。

正文、密码保护、回复后可见、评论提交、评论身份和插件信息继续使用博客核心渲染；点赞接入核心接口及 CSRF 验证。主题保留所有标准 action 钩子、管理员预览导航和「菜单管理」插件接管能力。

## 默认配置

编辑同目录的 `config.php` 即可覆盖主题选项，下次访问生效。未在博客后台提供的项目采用原版默认值：

| 项目 | 默认值 |
| --- | --- |
| Banner 标题 / 副标题 | Kratos / 专注于用户阅读体验的响应式博客主题 |
| Banner 背景 | 原版 `background.jpg` |
| 背景色 / 浏览器主题色 | `#f5f5f5` / `#282a2c` |
| 缩略图 / 摘要长度 | 开启 / 260 字符 |
| 阅读量、评论数、点赞数、作者 | 全部显示 |
| 文章侧栏 / 图片灯箱 | 开启 |
| 动画 / Font Awesome | 关闭 |
| 未配置的轮播、广告、打赏、微信二维码、侧栏随动 | 关闭 |

可用侧栏项为 `about`、`posts`、`tags`、`comments`、`categories`、`search`、`toc`，按 `sidebar` 数组顺序显示。最近评论默认显示 5 条，并排除密码保护内容。文章目录仅在详情页有对应标题时显示。

`navigation` 留空时显示首页、归档、分类、标签、链接及导航独立页面；支持在配置文件里指定自定义导航。启用「菜单管理」接管后优先显示统一菜单。`socials` 留空时读取首位作者的公开社交链接；没有设置则使用原版空社交栏。示例：

```php
'navigation' => [
    ['name' => '首页', 'url' => '/'],
    ['name' => 'GitHub', 'url' => 'https://github.com/yourname'],
],
'socials' => [
    ['icon' => 'github', 'name' => 'GitHub', 'url' => 'https://github.com/yourname'],
],
'sidebar' => ['about', 'posts', 'tags', 'toc'],
```

链接支持 HTTP(S) 地址或站内绝对路径；子目录安装时自定义站内链接需包含安装前缀。文章缩略图使用公开正文第一张图片，没有图片时使用原版 `default.jpg`。原版 WordPress 后台、SMTP、云存储、编辑器、短代码和第三方服务不属于主题前台移植；未添加对应后台或服务依赖。

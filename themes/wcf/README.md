# wcf

作者：**jkjoy**。适用 SBlog **1.14.30 及以上版本**。

参考 [xiaopanglian/icefox](https://github.com/xiaopanglian/icefox) 的微信朋友圈样式，为 SBlog 实现相同的窄栏动态布局、封面头像、图片九宫格、评论灰框和日夜模式。上游资料见 [UPSTREAM.md](UPSTREAM.md)。

## 安装与设置

将 `wcf` 目录放入博客的 `themes/`，确认路径为 `themes/wcf/theme.json`。进入“后台 → 主题管理”，可先在“更多 → 主题设置”配置，再打开预览或启用。

默认布局沿用 Icefox：576px 最大宽度、320px 封面、右下角头像与签名、左侧作者头像、蓝色作者名以及动态底部分隔线。封面图片和视频留空时显示原版浅灰色封面，头像留空时使用博客 Logo。移动端自动适配屏幕宽度。

主题设置独立保存在 SBlog 数据库中。切换主题不会删除这些设置。

| 设置分组 | 可配置内容 |
| --- | --- |
| 封面与个人资料 | 背景视频、封面图片、Logo / 头像、头像链接、朋友圈名称、签名 |
| 动态展示 | 长内容折叠、文章标题、评论预览及数量、动态翻页方式、标签、分类 |
| 发布定位与广告标记 | 默认定位、定位链接、按文章 ID 或 slug 指定定位和广告标记 |
| 外观与站点信息 | 默认日间 / 夜间 / 跟随系统、Gravatar 加速、备案信息、管理员发布入口 |
| 自定义代码 | CSS、JavaScript、统计 HTML |

访客可在页面右上角的设置面板中搜索文章、访问标签与页面、切换日夜模式。主题模式在当前浏览器中记忆。每页文章数量沿用“后台 → 基本设置”的配置。

“动态翻页方式”提供两种选择：选择“页码翻页”后，访客点击页码跳转到相应页面；选择“加载更多”后，访客点击按钮将下一页动态追加到当前列表。默认使用“加载更多”，前台只显示所选的一种方式。

## 发布动态

使用 SBlog 原生文章编辑器发布，支持正常的 Markdown 正文。朋友圈列表默认隐藏独立标题，正文直接显示为动态；需要显示博文标题时开启“显示文章标题”。长正文可点击“全文”展开，点击时间可访问文章详情。

图片使用 SBlog 的 Markdown 图片写法：

```markdown
今天的日常。

![照片一](/uploads/photo-1.jpg)
![照片二](/uploads/photo-2.jpg)
```

主题自动整理为朋友圈图片布局：单图按原比例展示，多图使用九宫格，四图使用两行两列，超过九张显示剩余数量。点击图片打开灯箱，可切换同一条动态的全部图片。

音视频可使用 SBlog 支持的正文媒体语法；音乐卡片也可使用以下短代码，媒体地址须是浏览器可直接播放的音频地址：

```text
[music title="歌曲名" artist="歌手" cover="https://example.com/cover.jpg" src="https://example.com/music.mp3"]
```

封面背景视频与文章内的视频独立配置。浏览器的自动播放策略可能限制背景视频播放，建议同时配置封面图片作为静态背景。

## 单篇定位与广告标记

SBlog 没有 Icefox 的 Typecho 文章自定义字段表单，主题在“单篇动态定位与广告配置”中提供 JSON 映射。键可以是文章 ID，也可以是 slug：

```json
{
  "12": {
    "position": "成都市 · 天府广场",
    "position_url": "https://example.com/map",
    "advertise": false
  },
  "my-daily-life": {
    "position": "家里",
    "advertise": true
  }
}
```

未指定的文章沿用默认定位。`advertise` 使用 JSON 布尔值 `true` 或 `false`。定位链接允许完整 HTTP(S) 地址或以 `/` 开头的站内路径，无效链接不会作为可点击地址输出。

## 评论与点赞

评论使用 SBlog 原生提交、审核和回复机制。动态预览只展示审核通过的公开评论；详情页保留完整评论表单、评论身份和信息插件钩子。全站或文章关闭评论时沿用 SBlog 的设置。

文章点赞可接入 SBlog 的 **article-likes** 插件。安装并启用插件后，主题显示真实的点赞状态与数量；未启用插件时不显示点赞入口，也不生成模拟计数。

搜索、列表摘要和图片提取遵守 SBlog 的密码内容及回复隐藏规则。密码保护内容通过详情页的原生解锁表单访问。

## 与上游的适配

Icefox 的封面视频、封面图片、Logo、头像链接、备案信息、Gravatar 加速、自定义 CSS / JS、统计代码、发布入口和自动折叠设置均提供对应入口。发布定位与广告标记使用上述主题设置映射。

文章发布与登录使用 SBlog 原生后台；友情链接使用 SBlog 的链接数据；评论和点赞分别使用 SBlog 核心与可选插件。主题不依赖 Typecho、Icefox 后端插件、Bulma、Alpine.js 或 jQuery。归档、标签、分类和独立页面继续使用 SBlog 路由。

主题目录不会修改 SBlog 核心文件。前台资源为主题自有文件，可随主题独立安装。

# Argon for Simple PHP Blog

将 [solstice23/argon-theme](https://github.com/solstice23/argon-theme) 的默认样式移植到 Simple PHP Blog。原版版本为 1.3.5，来源提交为 `c88262a2dd0252d0ecd15f2a31d338fad7f19215`。

直接保留原版 Argon 样式、Bootstrap 基础样式、图标字体和默认头像；适配层只负责 SBlog 的数据、表单及浏览器原生交互。默认主色 `#5e72e4`、背景 `#f4f5f7`、4px 圆角、双栏布局及 `71.8vh` 横幅均跟随原版。字体与图标本地加载，不依赖 CDN。

## 安装

1. 将 `argon` 目录放入博客的 `themes/`。
2. 后台 → 主题管理 → Argon，可先预览再启用。
3. 点击 Argon 的「主题设置」，修改并保存；未启用时也可以先配置。

主题使用 SBlog 原生通用主题设置，不需要配套插件，也无需修改核心程序。安装主题不会自动切换当前站点主题。

从 1.0.0 升级时，尚未保存原生设置的前台会继续读取旧插件配置。首次进入原生「主题设置」会显示主题默认值，请按旧配置核对填写后保存；保存后前台统一使用原生配置，即可停用并卸载 `argon-settings`。旧配置不会被删除或改写。

## 已适配的页面与交互

- 首页：置顶、摘要、封面、分类、标签、阅读时间及分页。
- 文章与独立页：Markdown 正文、原版排版、目录、前后篇导航、评论和回复。
- 归档时间线、分类索引、分类文章、标签索引、标签文章、友链及错误页面。
- 搜索弹窗：标题、摘要、公开正文搜索，支持分页与 `Ctrl / ⌘ K`。
- 原版手机抽屉菜单、自动/日间/夜间模式、阅读模式、工具栏换边和阅读进度。
- 主题色、字体、阴影、圆角的访客偏好保存在浏览器本地；可点击「恢复默认」。
- 代码复制、图片放大、键盘 Escape 关闭弹窗。

## 后台配置

主题随附 `settings.json`，由原生设置页提供 31 项配置，分为外观、横幅、侧栏、文章与页脚五个分区。

| 配置 | 说明 |
| --- | --- |
| 主色、背景、默认模式 | 默认模式可跟随系统；访客个人选择优先 |
| 字体、阴影、圆角 | 原版无衬线/衬线、浅/深阴影；圆角 0–24px |
| 沉浸色、纯黑深色 | 原版配色选项 |
| 导航标题、横幅标题/副标题 | 留空使用站名与站点标语 |
| 横幅背景、几何装饰、高度 | 高度 `0` 为原版响应式高度，或自定义 200–900px |
| 左右侧栏 | 关闭左侧栏使用单栏，手机导航仍可用；右侧栏显示分类及标签 |
| 头像、作者、简介、公告 | 公告/简介为纯文本，支持换行 |
| GitHub、邮箱、RSS | 站点概览中的社交链接 |
| 摘要、长度、阅读时间、前后篇、目录 | 按需显示文章辅助信息 |
| 页脚、建站年份、自定义 CSS | 页脚为纯文本；CSS 不需要 style 标签 |

配置独立保存于数据库 `settings` 表的 `theme_settings_argon` 项，为 JSON 对象。设置页沿用核心的管理员验证、CSRF 防护、颜色/URL/枚举校验和保存反馈。数值项按字段说明填写，前台会限制在有效范围；自定义 CSS 最多 20000 字符。切换或更新主题保留已保存的配置。

## 内容与兼容性

文章详情沿用核心已经生成的正文和评论，保留密码门禁、回复隐藏、评论审核、提交反馈、评论身份/信息插件钩子和 CSRF 防护。列表、搜索、封面和阅读时间只使用核心脱敏后的公开内容。主题预览中的站内链接会保留管理员预览参数。

要求 SBlog 1.14.18 或更高版本的原生主题设置接口；PHP 要求与博客核心相同，不额外要求 mbstring。支持普通参数链接、伪静态链接和子目录资源地址。保留全部标准主题 action、核心 SEO 信息、自定义 head 代码与备案页脚。

这是 SBlog 适配版。WordPress 专属的自定义文章类型、说说、点赞、WP 小工具、短代码、打赏和 PJAX 插件生态没有迁入；正文与评论数据由 SBlog 管理。样式复用原文件，表单和部分页面结构按 SBlog 的功能做了适配，不能将其视为对所有 WordPress 扩展页面逐像素一致的保证。

## 验证

开发时使用独立 SQLite 数据库和本地 HTTP 服务，覆盖公开页面、资源、查询/伪静态分页、搜索、评论提交与回复、密码访问、回复隐藏、预览与后台配置；另以桌面和 390px 手机视口检查实际交互。运行 PHP lint 与 JavaScript 语法检查。

# 旧日小屋 · Retro Home

基于提供的「复古个人主页.html」制作的 SBlog 主题。保留米色纸张、点阵背景、宋体、像素软盘、760px 页面、虚线分栏和机械数字计数器，小屏幕自动改为单栏。

适用于 **SBlog 1.14.18 及以上版本**，在 1.14.36 验证。无需构建、外部字体或额外插件。

## 使用

将 `retro-home` 文件夹放入博客的 `themes/` 目录，在「后台 → 主题管理」找到 **旧日小屋 · Retro Home**，预览或启用。在该主题的「更多 → 主题设置」中修改欢迎语、个人资料、联系邮箱、状态、摘句和侧栏开关。站名、页脚与备案号使用博客设置。

首页的「最近更新」展示真实的已发布文章，遵循置顶与「每页文章数」设置，标题右侧提供分页。欢迎语、关于我和友链仅在第一页展示。友情链接读取后台友链数据，首页最多显示 6 项，超出时显示完整列表入口；填写联系邮箱后显示「交换链接」。留空个人资料中的单项即可隐藏对应行；邮箱为空或格式无效时隐藏邮箱链接。

导航包含首页、关于我、更新日志、友情链接和博客的导航页面。若需要留言簿，可新建一个允许评论的独立页面并加入导航。兼容菜单管理插件的导航接管。

## 日期与计数

- 侧栏时钟显示访客设备的本地时间。
- `LAST UPDATE` 为已发布内容的最近修改日期。
- 建站日期留空时使用最早已发布内容的日期，没有内容时不显示日期。
- 数字计数器是已发布文章的阅读次数之和，沿用核心计数规则；不是独立访客数，也不会通过刷新首页生成虚假访问记录。
- 最新文章在发布后的 7 天内显示 `NEW`；置顶文章优先显示「置顶」。

## 兼容

支持文章、独立页面、归档、分类、标签、友链和错误页面。详情正文、密码解锁、回复后可见、评论表单及评论插件信息继续由博客核心渲染。保留全部标准布局钩子、SEO 元信息、RSS、后台主题预览与自定义 head 内容。无需 JavaScript 即可阅读和导航，时钟与评论回复按钮使用本地脚本。

主题本身不请求外部字体、图片或统计服务。文章、插件和核心评论头像仍可使用站点配置的外部资源。

# Sunny

适用于 SBlog 的 Sunny 主题，参考 [喵喵小站](https://www.mmbkz.cn/) 的实际桌面及手机页面实现。

将 `sunny` 文件夹放入 `themes`，在后台「主题管理」中预览或启用。主题使用博客已有的站名、简介、头像、公告、导航页面、文章、分类、标签和评论，无须修改核心文件。

在「主题管理 → Sunny → 更多 → 主题设置」的「首页公告」中可自定义公告内容，最多 2000 字，支持换行并以纯文本显示，仅出现在首页文章列表上方。首次保存前沿用站点原有的 `home_intro` 公告；保存后使用主题设置中的内容，留空保存显示「暂时没有新的内容」。设置独立保存于数据库，升级或切换主题不会丢失。

包括居中头像页头、横向分类菜单、动态文章卡片、Steam 玩家卡片、文章日历、近期评论、标签和归档、手机底部导航。支持本地文章搜索（Ctrl / ⌘ + K）、浅色与暗色模式、文章目录、图片放大、阅读足迹和小苗浇水。

宽屏时，版权、备案及主题署名显示在右侧栏的「站点信息」中，页脚保留装饰图；屏幕宽度不超过 1120px、侧栏收起后，页脚显示这些信息及 RSS、站点地图链接。

文章详情页的「上一篇」「下一篇」导航显示对应文章标题，长标题自动换行。

首页、分类与标签列表的文章卡片会按正文顺序提取 Markdown 图片、HTML 图片及图片直链，合并封面并去重，按原版的 1～9 张图片拼图排列。单图保留比例，三图为左大右侧上下两小图，四图为四宫格，九图为九宫格；图片组最大宽度 400px，手机端自动缩小。超过九张时，第九张标出剩余数量，点击图片可放大并切换查看同篇全部图片，支持左右方向键和触摸滑动；关闭 JavaScript 时可直接打开原图。代码示例、密码保护文章与回复隐藏内容中的图片不会进入卡片。

侧栏「近期评论」采用圆形头像、竖向时间线与两行气泡摘要；长昵称自动省略，悬停可查看来源文章，点击跳到原评论。头像沿用站点配置的头像来源，加载失败时显示昵称首字。

左上角社交图标读取后台「用户设置 → 社交链接」中的站长资料，仅显示已填写的有效链接。品牌图标使用本地 Remix Icon 4.6.0 SVG，授权见 `assets/social-icons-LICENSE.txt`。

文章卡片的作者名读取该文章作者在「用户设置」中填写的昵称，未填写时显示用户名。网站名继续用于站点标题。

侧栏玩家卡片读取「Steam 游戏展示（steam-showcase）」插件中的 Steam 头像、昵称、在线状态和游戏数量，点击游戏数量可进入游戏页。未启用插件、未填写 API Key / Steam ID 或没有可用玩家资料时，整张卡片隐藏；不使用博客用户资料和文章数量代替。游戏详情未公开时数量显示「—」，同步失败但仍有缓存时显示上次同步时间。主题复用插件缓存，不单独请求 Steam API。

Steam 游戏页参照原版使用圆形头像名片、统计、游戏封面卡片、胶囊搜索与排序按钮和每页 48 款的数字分页，支持手机及浅色、暗色模式。关闭 JavaScript 时仍可查看完整游戏库。展示内容遵循插件的最近游玩、游戏库和导航开关；插件未提供的 Steam 等级、好友及成就数据不额外显示。

在「主题管理 → Sunny → 更多 → 主题设置 → 音乐播放列表」启用音乐播放器，填写网易云公开歌单链接或 ID 即可读取歌曲，也可设置标题、歌曲数量、默认音量及播放模式。未启用或未填写有效歌单时隐藏播放器。侧栏封面卡片与导航栏音乐按钮可打开右侧歌单，支持选曲、播放／暂停、上一首／下一首、停止、进度拖动、音量、列表循环、单曲循环及随机播放；播放时显示小型浮动控制条，手机端位于底部导航上方。

播放器使用浏览器原生音频，访客点击后开始播放；浏览器保存同一歌单的选曲、进度、音量和播放模式，重新进入页面仍需手动开始播放。歌单资料从网易云官方公开接口读取，每小时缓存一次，暂时无法同步时可继续显示最近一次歌单。音乐直接由网易云提供，版权、会员或地区限制可能导致部分歌曲无法播放，此时可切换歌曲或打开网易云歌单。未开启 JavaScript 时可通过卡片中的链接进入网易云收听。

界面线条图标参考 Lucide / Feather，许可及版权声明见 `assets/icons-LICENSE.txt`。主题需要 SBlog 1.14.18 或更新版本。

文章点赞功能依赖「文章点赞（article-likes）」插件。将配套的 `article-likes` 文件夹放入 `plugins`，到后台「插件管理」启用后，首页、分类和标签列表以及文章详情页会显示可点击的点赞按钮。数量保存在服务器数据库中，同一 IP 对同一篇文章只能点赞一次，刷新后保留，不支持取消点赞；停用插件会隐藏按钮，已保存的点赞数据会保留。主题本身不记录点赞数据。

有评论的文章卡片按原版样式，在同一个浅灰容器中显示最新 3 条已审核评论，最新回复排在前面；头像、昵称及回复对象与正文同行，点击可跳转到原评论，右下角「MORE」进入全部评论。卡片预览仅显示评论基础信息，不展示增强插件的等级、浏览器和 IP 归属地等内容。密码保护文章不显示卡片评论预览，待审核及垃圾评论不会公开。文章详情的完整评论区继续保留 SBlog 的插件钩子。

文章和独立页面的完整评论区参照原版，将发表表单放在列表前，使用头像、浅灰气泡与同卡片内的回复；站长评论靠右显示。手机端访客资料竖排，点击头像上的回复按钮可选择回复对象。保留核心表单校验、审核提示及评论身份和信息插件；关闭 JavaScript 时使用核心评论顺序与表单。

文章和评论沿用 SBlog 的内容门禁、回复表单与插件钩子；搜索与封面仅取公开内容。搜索索引上限为 2000 篇文章。阅读足迹与配色偏好保存在访客浏览器中。

`assets/plant.webp` 和 `assets/footer.webp` 为参考站公开页面使用的装饰素材；页面其余部分以独立 PHP、CSS 与 JavaScript 实现。字体优先使用设备上的 Noto Sans SC，未安装时使用系统中文字体。第三方账号、音乐和游戏资料由站点实际配置的插件提供，本主题不内置参考站的个人资料。

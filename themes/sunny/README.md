# Sunny

适用于 SBlog 的 Sunny 主题，参考 [喵喵小站](https://www.mmbkz.cn/) 的实际桌面及手机页面实现。

将 `sunny` 文件夹放入 `themes`，在后台「主题管理」中预览或启用。主题使用博客已有的站名、简介、头像、公告、导航页面、文章、分类、标签和评论，无须修改核心文件。

包括居中头像页头、横向分类菜单、动态文章卡片、博主信息、文章日历、近期评论、标签和归档、手机底部导航。支持本地文章搜索（Ctrl / ⌘ + K）、浅色与暗色模式、文章目录、图片放大、阅读足迹和小苗浇水。

左上角社交图标读取后台「用户设置 → 社交链接」中的站长资料，仅显示已填写的有效链接。品牌图标使用本地 Remix Icon 4.6.0 SVG，授权见 `assets/social-icons-LICENSE.txt`。

界面线条图标参考 Lucide / Feather，许可及版权声明见 `assets/icons-LICENSE.txt`。主题需要 SBlog 1.14.13 或更新版本。

文章点赞功能依赖「文章点赞（article-likes）」插件。将配套的 `article-likes` 文件夹放入 `plugins`，到后台「插件管理」启用后，首页、分类和标签列表以及文章详情页会显示可点击的点赞按钮。数量保存在服务器数据库中，同一 IP 对同一篇文章只能点赞一次，刷新后保留，不支持取消点赞；停用插件会隐藏按钮，已保存的点赞数据会保留。主题本身不记录点赞数据。

有评论的文章卡片按原版样式，在同一个浅灰容器中显示最新 3 条已审核评论，最新回复排在前面；头像、昵称及回复对象与正文同行，点击可跳转到原评论，右下角「MORE」进入全部评论。卡片预览仅显示评论基础信息，不展示增强插件的等级、浏览器和 IP 归属地等内容。密码保护文章不显示卡片评论预览，待审核及垃圾评论不会公开。文章详情的完整评论区继续保留 SBlog 的插件钩子。

文章和评论沿用 SBlog 的内容门禁、回复表单与插件钩子；搜索与封面仅取公开内容。搜索索引上限为 2000 篇文章。阅读足迹与配色偏好保存在访客浏览器中。

`assets/plant.webp` 和 `assets/footer.webp` 为参考站公开页面使用的装饰素材；页面其余部分以独立 PHP、CSS 与 JavaScript 实现。字体优先使用设备上的 Noto Sans SC，未安装时使用系统中文字体。第三方账号、音乐和游戏资料由站点实际配置的插件提供，本主题不内置参考站的个人资料。

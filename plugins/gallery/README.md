# 图库

图库插件复用 SBlog 媒体库中的图片，并提供分类、说明、排序、发布状态、公开图库页面和键盘可用的灯箱。

## 使用

1. 在“插件管理”启用“图库”。
2. 打开“图库管理”，从媒体库选择图片或上传新图片。
3. 按需建立分类，并在“设置”中修改公开页标题、描述、路由和每页数量。
4. 默认公开地址为 `/gallery`；未启用伪静态时使用 `index.php?a=gallery`。

插件只保存媒体关联。从图库移除图片不会删除媒体库中的原文件；停用或升级插件也会保留图库数据。

图库路由只支持单段小写字母、数字和连字符。若路由与独立页面或系统地址冲突，插件会拒绝保存。

# 图库

图库插件复用 SBlog 媒体库中的图片，并提供分类、说明、排序、发布状态、公开图库页面和键盘可用的灯箱。

## 使用

1. 在“插件管理”启用“图库”。
2. 打开“图库管理”，从媒体库选择图片或上传新图片。
3. 按需建立分类，将图片加入分类并设置排序。公开分类卡片自动以该分类第一张已发布图片作为缩略图，按排序值升序、同值时新加入的图片优先。
4. 在“设置”中修改公开页标题、描述、路由和每页数量。
5. 默认公开地址为 `/gallery`；未启用伪静态时使用 `index.php?a=gallery`。首页先显示分类列表，点击分类进入图片列表；未分类的公开图片有独立入口。分类内保留分页、原图灯箱和返回分类列表链接。

插件只保存媒体关联。从图库移除图片不会删除媒体库中的原文件；停用或升级插件也会保留图库数据。

图库路由只支持单段小写字母、数字和连字符。若路由与独立页面或系统地址冲突，插件会拒绝保存。

添加图片时，只有服务器确认新增或已存在的图片才会标为“已加入”。失效图片会保留选择并显示错误；上传成功但关联失败时，可重试加入图库，无需重复上传。

支持 GD 的服务器会为本地图片按需生成缩略图，网格和分类封面使用缩略图，灯箱仍打开原图。远程图片、GIF、小图或超出处理预算的图片会自动使用原图；JPEG 在缺少 EXIF 扩展时也使用原图，以保留照片方向。缩略图缓存位于 `cache/gallery-thumbnails/`，限制为 1000 个文件或 128 MiB，可直接删除重建；无需数据库迁移。

## 验证

```bash
node scripts/test-gallery-admin.cjs
php scripts/test-gallery.php
php scripts/test-gallery-media.php
```

完整扩展检查使用 `php scripts/test.php` 和 `php scripts/validate.php`。GD 和 EXIF 为可选扩展；自动化检查启用它们，以验证实际缩略图生成和照片方向。

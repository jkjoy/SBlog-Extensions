# 访问日志

适用于 SBlog 1.14.8 及以上版本。在后台查看每日访问情况，不需要第三方统计服务或额外的前台脚本。

## 使用

1. 将 `visit-log/` 安装到站点的 `plugins/` 目录，或安装商店发布的 ZIP 包。
2. 在“后台 → 插件管理”启用“访问日志”，点击该插件的设置入口。
3. 页面默认展示今天的数据。服务器使用其他时区时，可将“统计时区”设为 `Asia/Shanghai` 后保存。

启用后开始记录访问，不能恢复启用前的历史数据。暂停记录或停用插件会保留已有日志。

## 后台内容

- 访问量（PV）、估算访客数（UV）、独立 IP 数、爬虫访问数。
- 当天 24 小时访问分布、热门页面和来源站点。
- 每条访问的时间、页面、IP、来源、设备、浏览器、操作系统、HTTP 状态、服务器处理耗时和 User-Agent。
- 按日期、精确 IP、页面路径片段及普通访客 / 爬虫筛选。统计和列表使用相同条件，明细每页 50 条。
- 开关记录、选择是否记录爬虫、调整统计时区及保留天数（1、7、30、90、180、365 天）。

默认开启记录，包含爬虫，保留 30 个自然日（含今天）。旧日志在有访问或管理员打开页面时自动清理；暂停记录期间打开后台也会清理。缩短保留期限后，超期日志会删除。

## 统计口径

只记录 SBlog 公开页面的 GET 请求：首页与搜索、文章、独立页面、归档、标签、分类、友情链接及图库插件页面。已登录管理员的访问、预览、后台、登录、API、POST / HEAD、RSS、站点地图和静态资源不计入。

通过 `request` 钩子提前安排 shutdown 回调，在请求结束时写入一条记录，兼容静态页面缓存命中后直接退出的行为。文章不存在等已进入公开路由的错误响应也会记录；在核心路由钩子之前被拒绝的请求（如未匹配的漂亮链接 404）不计入。Web 服务器或 CDN 直接返回且未运行 PHP 的请求不计入。

UV 使用当天的 IP 与 User-Agent 组合，通过站点随机密钥生成摘要估算，不设置追踪 Cookie。同一 IP 下使用相同浏览器的不同人可能合并统计，切换网络或浏览器可能分别统计。爬虫识别依赖 User-Agent 特征，可使用“普通访客”筛选查看不含爬虫的数据。处理耗时指 PHP 请求到记录写入前的耗时，不表示页面停留时间或浏览器加载耗时。

## 存储

数据保存在站点现有 SQLite 数据库的 `sblog_visit_logs` 和 `sblog_visit_log_settings` 表中。日志查看和设置修改使用核心管理员鉴权；修改设置需要 POST 与 CSRF 校验。写入异常只进入服务器错误日志，不影响公开页面响应。

IP 来自校验后的 `REMOTE_ADDR`，不直接采信访客传入的代理头；使用反向代理时应在 Web 服务器配置真实 IP。访问地址只保留 `a`、`id`、`slug`、`p`、`q`、`category`、`uncategorized` 这些路由与搜索参数，来源地址移除用户名、密码、查询参数和片段。IP、搜索词、来源路径及 User-Agent 仍属于访问日志内容，只在管理员页面显示。

日期边界、小时分布和显示时间统一使用“统计时区”，默认沿用 PHP 时区。切换时区会按新时区重新划分已有日志的日期；UV 摘要按记录时的日期生成，切换后边界附近的估算 UV 可能有差异。

# 字体安装器

从“插件管理”启用后进入“设置”，上传 WOFF2、WOFF、TTF 或 OTF 字体。上传会立即应用到所有前台主题；设置页可切换历史字体、恢复主题默认字体或删除字体及其服务器文件。后台界面、代码和图标字体不受影响。

字体文件保存在站点的 `uploads/font-installer/`，元数据保存在站点 SQLite 数据库中。升级或停用插件不会删除上传的字体；停用后前台自动恢复主题字体。卸载插件也不会删除用户上传的字体和数据库记录，请先在设置页删除不再需要的字体。

单个字体最大 30 MB。插件同时校验扩展名和文件头，不接受伪装成字体的其他文件。建议优先使用体积更小的 WOFF2，并确认所上传字体的网页使用授权。

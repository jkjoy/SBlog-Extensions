# 评论抽奖测试

在项目根目录运行：

```powershell
php plugins/comment-lottery/tests/run.php
```

本机的 PHP 也可直接指定：

```powershell
& D:/EServer/core/childApp/php/php-8.4/php.exe plugins/comment-lottery/tests/run.php
```

需要 PHP 8.2 或更高版本、`pdo_sqlite` 扩展以及允许 `proc_open`。测试入口只允许 CLI，直接加载插件抽奖引擎与公开视图，使用内存 SQLite 和邮件函数替身。并发测试将一份测试数据库复制到独立临时目录，启动两个 PHP 进程同时开奖，结束后删除临时文件。不会加载博客主入口、读取或修改正式数据库、访问网络或发送真实邮件。

覆盖配置校验、上海时区、新文章首次保存和复制标记保护、代码示例标记、评论资格与时间边界、邮箱去重、回复规则、随机抽取数量、数据库失败回滚、无人参与、顺序和双进程并发开奖幂等、自动开奖条件及失效模块积压、开奖后的规则与评论快照保护，以及失败邮件重试间隔和次数、成功邮件防重、中断发送防重。

公开视图回归测试通过真实 PHP 输出缓冲回调执行，覆盖模块渲染、中奖内容转义、邮箱不公开、密码门禁不泄露、撤下评论不公开快照、模块在文章开头时自动摘要不含短代码、自定义摘要保留。文章查找和摘要函数使用简化的核心替身；完整主题集成及实际 SMTP 投递需要在隔离环境另行验证。

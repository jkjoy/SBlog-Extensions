# 多媒体解析

将文章或独立页面中独占一段的媒体链接转换为播放器，支持：

- 哔哩哔哩：BV、av 视频地址及 `p` 分集参数。
- YouTube：观看页、`youtu.be` 短链接、嵌入页、Shorts 和直播地址。
- 网易云音乐：单曲、歌单和专辑地址，包括 `#/song?id=...` 形式。

## 安装与使用

将本目录放到站点 `plugins/multimedia-parser/`，在后台“插件管理”启用“多媒体解析”。无需额外设置。在正文中把完整的 HTTP 或 HTTPS 链接单独放在一段，例如：

```markdown
https://www.bilibili.com/video/BV1xx411c7mD/?p=2

https://www.youtube.com/watch?v=dQw4w9WgXcQ

https://music.163.com/#/song?id=186016
```

链接与其他文字放在同一段时仍显示普通链接。音乐默认关闭自动播放，视频保持 16:9 比例，音乐播放器按类型设置高度。

插件在公开页面的主题 `head` 钩子中加载样式，确保 AJAX 加载更多或无限滚动追加的播放器也能正常显示。未提供该钩子的自定义主题会在页面实际包含播放器时由 HTML 输出过滤器补充样式，同一页面不会重复加载。后台页面不通过主题钩子加载播放器样式。

插件通过核心的 `media_embed_html` 钩子提供解析，不会发起服务端平台请求，不接管豆瓣等其他插件已处理的链接。停用后，新版核心将媒体地址显示为普通链接，文章原文不变。浏览器播放仍需要能够访问对应平台。

需 Simple PHP Blog 1.14.31 或更高版本。自此版本起，核心不再内置平台解析，需启用本插件使用上述播放器。

## 本地验证

```powershell
php plugins/multimedia-parser/tests/parser.php
```

验证不访问外部平台，也不修改站点数据库或文章。

# 付费阅读

适用于 SBlog 1.14.8+、PHP 8.2+。支持支付宝电脑网站 / 手机网站支付，以及微信支付 API v3 H5 支付，参考 [jkjoy/pay](https://github.com/jkjoy/pay) 的 `Yansongda\Pay\Pay` 接口。插件附带生产依赖和固定版本的 Composer 锁文件。

## 使用

1. 在插件管理中启用「付费阅读」，打开插件设置。
2. 在站点设置中填写准确、可公网访问的 **HTTPS 站点地址**。
3. 填写收款商户信息、私钥和证书，再启用对应支付方式。支付宝使用证书模式，需开通电脑网站 / 手机网站支付；微信需开通 H5 支付并配置 H5 域名。微信内置浏览器和桌面扫码支付暂不支持。
4. 编辑文章或独立页面，在正文标签旁勾选「付费阅读」并填写人民币价格。
5. 需要免费试读时，在正文单独一行插入 `<!-- paid-reading -->`。分隔符之前公开，之后付费；没有分隔符则整篇正文付费。每篇仅允许一个分隔符，并应放在代码块之外。

```markdown
这里是免费试读的介绍。

<!-- paid-reading -->

## 完整内容

读者付款后可以阅读这里的正文。
```

保存后，摘要会重新从免费试读部分生成；不保留可能包含付费正文的旧摘要。管理员可直接查看完整正文。取消勾选并保存会将正文公开。

## 支付配置

支付宝需提供 App ID、Seller ID、应用私钥、应用公钥证书、支付宝公钥证书和根证书。支持沙箱模式，正式收款前应关闭沙箱。

微信需提供商户号、应用 App ID、商户私钥、商户证书、32 字节 API v3 密钥，以及平台证书或支付公钥映射。例如：

```json
{
  "完整平台证书序列号": "/secure/wechat-platform.pem",
  "PUB_KEY_ID_实际公钥ID": "/secure/wechat-public-key.pem"
}
```

证书和私钥可填写 PEM 内容或服务器绝对文件路径，建议将文件放在 Web 公开目录之外。密钥表单不回显已保存的密钥，留空保留旧值。平台轮换证书时可以同时保留多个序列号。

通知地址由配置的站点地址生成，不依赖请求 Host：

```text
https://你的站点/index.php?a=paid_reading_notify&channel=alipay
https://你的站点/index.php?a=paid_reading_notify&channel=wechat
```

读者发起购买后跳转支付平台，返回后自动轮询本地订单状态。浏览器返回参数不用于解锁；仅 SDK 验签、微信解密且订单号、商户、应用、实际金额和支付状态均匹配的异步通知可以解锁。重复通知幂等处理，管理员已撤销的订单不会被重复回调重新授权。创建订单使用服务器保存的文章价格，金额以整数分计算。

## 权限与订单

- 访客无需注册。购买权限通过随机的 HttpOnly、Secure、SameSite=Lax Cookie 绑定当前浏览器，Cookie 有效期一年。订单号或返回链接本身没有阅读权限。
- 一次购买可阅读该文章后续更新。改价不影响已付款订单；已有待支付订单仍按下单金额验证。
- 清除 Cookie、换浏览器或设备后不自动恢复权限。当前版本没有账号绑定、找回码或跨设备恢复功能。
- 插件设置的「订单与权限」可查看订单并撤销授权；退款需要在支付平台另行操作。如果同一浏览器有多笔已付款订单，需逐笔撤销才能完全收回该文章权限。
- 支付窗口可设为 5–120 分钟；已支付但延迟到达的有效通知仍会解锁。

## 正文保护及兼容性

付费正文单独保存在站点 SQLite 数据库的 `sblog_paid_reading_content` 表中，公开 `posts.content` 只存试读内容和不授予权限的随机引用。RSS、搜索、摘要、主题元信息和公开 REST API 不会取得付费正文；已购买内容仅在对应文章详情页动态渲染。编辑器在后台重新载入原文。

支持已有密码保护和回复可见规则，付费解锁不会绕过这些规则。与静态页面缓存插件同时启用时，付费详情会绕过缓存并发送 `private, no-store` 响应头。外部 CDN 也应遵守此响应头，备份、旧缓存和此前公开的正文需由站点管理员自行管理。媒体库附件的直接下载地址仍遵循站点原有规则，此插件仅控制正文阅读权限。

REST API 可以读取试读内容、更新文章元数据，但必须保留原始公开正文引用。付费正文和定价应在站点编辑器中修改；接口提交替换正文会被拒绝。插件停用后付费正文依然不会被公开，重新启用后恢复阅读和编辑。

插件表与密钥保存在站点数据库中，卸载不会自动删除。备份或迁移站点时请保留数据库、密钥文件和插件依赖。每次保存付费正文会创建不可变版本，避免正文保存失败时破坏上一版；当前版本保留旧版本，不自动清理。

## 依赖与开发验证

支付 SDK 固定到引用仓库提交 `d1b354bc7808d00b75dd7b2038eb5359e90bafec`，生产依赖附带各自许可证。手动恢复依赖时，在插件目录运行：

```sh
composer install --no-dev --prefer-dist --no-plugins --no-scripts
```

PHP 需要 `openssl`、`bcmath`、`simplexml`、`libxml`、`json`，以及 SBlog 所需的 SQLite、mbstring 等扩展。

```sh
php scripts/test-paid-reading.php
php scripts/test.php
php scripts/validate.php
```

测试覆盖权限隔离、回调业务校验、幂等与撤销、正文保存失败时拒绝写入，以及编辑器、REST、缓存兼容性。上线前还需使用自己的商户凭据验证真实下单、异步通知和退款流程。

# Argon 主题设置

在“插件管理”启用本插件后，打开“扩展设置 → Argon 主题设置”。配色、横幅、作者资料、侧栏、文章摘要、目录和页脚均可在后台修改。

配置以 JSON 保存到博客数据库中的 `argon_options`，主题与插件均不需要写入自身目录。插件停用后保留已有配置，主题仍可正常显示；启用插件不会自动切换主题。

所有设置统一提交、统一保存；切换后台设置标签页时保留未保存的输入。图片支持 HTTP(S) 地址及以 `/` 开头的站内路径，公告和页脚使用纯文本。自定义 CSS 仅接受 CSS 规则，不填写 `<style>` 标签。

横幅高度默认为 `0`，使用原版的 `71.8vh`，随视口高度变化；指定像素高度时范围为 `200–900`。字体风格、卡片阴影、沉浸式主题色与纯黑深色背景也可在“外观”中选择。

要求 SBlog 1.14.16 或更高版本，与 Argon 主题配套使用。

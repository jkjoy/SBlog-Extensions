# Document 主题设置

安装 `themes/document/` 主题与本插件，在“插件管理”启用本插件，再进入“扩展设置 → Document 主题设置”。启用插件不会自动切换主题；请在“主题管理”预览或启用 Document。

设置包括原版绿色配色、背景色、白天 / 暗黑模式、调色板、Logo 与标题、搜索、单 / 双栏列表、缩略图位置、摘要、首页横幅、分类侧栏、作者资料、公告、社交链接、最新文章、阅读目录、上一篇 / 下一篇、版权、赞赏、页脚与备案信息。页脚支持自定义 CSS。

所有分区共用一个表单，“保存全部设置”统一保存；切换后台标签页保留未保存的输入。图片接受 HTTP(S) 地址和以 `/` 开头的站内路径。公告、简介、版权、页脚均为纯文本；版权支持 `{title}`、`{url}`、`{author}` 占位符。CSS 只填写规则，不包含 `<style>` 标签。

配置以 JSON 存入博客数据库的 `document_options`。主题不依赖本插件加载：插件停用后保留配置，前台仍可正常显示。卸载主题后插件设置页会提示重新安装，保留已有配置。

这是一份 SBlog 适配版，不运行 WordPress。原版中依赖 WordPress 的古腾堡编辑器、菜单与小工具管理、SMTP、Gravatar 服务、SEO 元信息、固定链接改写由 SBlog 站点设置或对应插件管理；WordPress 设置不会自动导入。

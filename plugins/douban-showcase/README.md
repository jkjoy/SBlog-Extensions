# 豆瓣记录展示

输入豆瓣用户 ID，在 SBlog 中展示该用户公开的电影、图书和音乐列表。支持看过 / 想看 / 在看、读过 / 想读 / 在读、听过 / 想听 / 在听，展示封面、个人评分、标记日期、短评和标签。

## 安装与使用

1. 将整个 `douban-showcase` 目录放入博客的 `plugins/`。
2. 在后台「插件管理」启用 **豆瓣记录展示**，点击「设置」。
3. 输入用户 ID，例如 `1000001` 或 `ahbei`，也可粘贴 `https://www.douban.com/people/ahbei/` 这样的完整个人主页地址。ID 是 `/people/` 后面的数字或自定义英文名称，不是显示昵称。
4. 保存设置，点击「查看展示页」。首次打开会自动获取电影记录，切换分类或状态会获取相应列表。

开启博客伪静态后，展示页使用 `/douban`，图书示例：`/douban?type=book&status=collect`；支持 `/douban/` 和子目录部署（例如 `/blog/douban`）。导航、分类、状态与后台「查看展示页」会自动使用这个地址。

未开启伪静态时使用 `index.php?a=douban`；原查询入口始终可用。启用插件后，`douban` 独立页面路径由插件展示页接管。默认主题导航可自动添加入口；自定义主题请手动添加展示页链接。Web 服务器需要将不存在的路径转交 `index.php`，可使用博客自带的 Apache `.htaccess` 或后台提供的伪静态配置。

无需 API Key、密码或登录 Cookie。插件仅获取豆瓣对未登录访客公开的记录；私密记录或要求登录验证的页面无法获取。

## 展示与同步

- 支持三种分类、三种记录状态。分类和状态链接在没有 JavaScript 时也可使用。
- 默认每批展示 12 条；搜索只查询已经同步的标题、介绍、短评与标签。「加载更多」继续显示已同步的记录。禁用 JavaScript 时显示全部已同步条目。
- 默认每份列表同步最近 3 页，可配置 1–10 页；豆瓣通常每页 15 条。插件去除重复条目，因此实际同步数量可能少于页数 × 15。
- 同步页数限制用于控制请求耗时，不代表全部历史记录。页面同时显示已同步数量、豆瓣返回的总数，以及完整豆瓣列表链接。
- 后台可选择一个分类和状态，点击「立即同步」。其他列表在首次浏览时自动同步，避免一次请求所有分类。
- 可选在首页文章列表下方展示最近看过的电影，最多 4 条，附完整展示页链接；需要主题保留 `content_after` 钩子。
- 封面直接使用豆瓣图片 CDN，设置无来源请求。图片加载失败显示本地占位图。

## 缓存与失败处理

默认缓存 360 分钟，可配置 5–1440 分钟。缓存以用户、分类、状态和同步页数区分，存在博客 `cache/` 目录。并发同步使用文件锁，失败后有 5 分钟冷却，手动同步也遵守该冷却。

临时故障时保留最多 7 天内的成功记录，并显示故障提示及同步时间。首次同步在后续分页中断时，保留已获取的部分记录，并明确提示同步中断。单份列表同步有 20 秒总网络预算。

明确返回私密状态时停止展示相应记录，同时使该列表其他同步页数的旧缓存失效，防止切换设置后重新展示；其他公开分类可继续显示。空列表、未配置账号、用户不存在、访问限制和解析失败均有对应说明；登录或验证码页面不会当作「没有记录」。

豆瓣可能限制服务器 IP 或调整页面结构。当前实现基于公开页面解析，不能保证所有账号、分类和服务器都能持续获取；图书页若返回 403，会显示无法获取提示。插件不使用第三方代理或绕过登录验证。

配置单独保存在数据库 `plugin_douban_settings` 表，不修改博客文章、账号或核心程序。停用插件后展示入口消失，配置与缓存保留。自定义布局应保留 `head` 和 `body_close` 钩子，以加载展示页样式和交互。

## 运行要求与验证

需要 SBlog 1.14.8 的插件/主题接口、PHP 8.0+、PDO SQLite、cURL、DOM/libxml，以及服务器连接豆瓣的能力。请保留项目对 `data/`、`cache/` 和插件 PHP/JSON/Markdown 文件的访问限制。

无需真实账号、不会读取现有博客数据库或发出豆瓣请求的本地检查：

```sh
php plugins/douban-showcase/tests/run.php
php plugins/douban-showcase/tests/integration.php
```

测试覆盖公开 HTML 解析、分页、反爬与隐私状态、缓存与失败恢复，以及配置校验、管理员/CSRF、转义、子目录链接和主题钩子。
